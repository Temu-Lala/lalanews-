
# Ethio News App

**Ethio News** is a social media platform designed for Ethiopians to stay connected, share news, and discuss current events. The app allows users to access the latest news, interact with posts, and engage in meaningful conversations around local and international events.

## Features

- **Browse News**: View the latest news articles categorized by topic such as politics, sports, entertainment, and more.
- **User Interaction**: Like, comment, and share news posts to interact with the community.
- **Video Streaming**: Watch video content related to the latest events and trends.
- **User Profiles**: Create and manage your personal profile to share updates, photos, and thoughts with your network.
- **Localization**: Focused on Ethiopian news, but includes global events and topics.
- **Real-time Updates**: Get the latest news and updates as they happen.
- **Responsive Design**: Optimized for both mobile and tablet views for a seamless experience.

## Tech Stack

- **Frontend**: Built with [Expo](https://expo.dev/), utilizing React Native for native mobile development.
- **Backend**: (To be developed) - Will handle user authentication, article management, social interactions (likes, comments), and video streaming.
- **UI Components**: Material UI and custom components for a responsive and modern design.
- **State Management**: Zustand for global state management.
- **Internationalization**: i18n-js for supporting multiple languages, including Amharic.

## Installation

To get started with the development of **Ethio News App**, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/Temu-Lala/lalanews.git
   cd lalanews

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the app in development mode:

   ```bash
   npx expo start
   ```

   * For mobile: Use [Expo Go](https://expo.dev/tools) to run the app on your device.
   * For web: You can open the app in the browser.

4. To run on web:

   ```bash
   npm run start-web
   ```

5. If you need to run with development debugging, use:

   ```bash
   npm run start-web-dev
   ```
